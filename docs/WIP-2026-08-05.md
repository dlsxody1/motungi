## 1번 — 데이터 정합성 (진행 중)

### 무엇이 문제였나

"신정동 → 문화공연 → 주말 → 방전형" 진단의 원픽이
`[마포구립서강도서관] 8월/어린이 2026 어린이 여름 독서교실` (10~12시)였다.

**근본 원인은 스코어링이 아니라 적재다.** culture 어댑터가 장르·대상·종료시각을 전부 버려서,
5축 중 3축(cost·difficulty·time)이 0.5 중립으로 붕괴하고 fit도 사전 카테고리 필터 때문에
1.0 상수가 된다 → 사실상 노이즈로 정렬되는 상태였다.

### 조사 중 뒤집힌 전제 (중요 — 내일 이걸 잊으면 잘못 고친다)

1. **`USE_TRGT`(이용 대상)가 이미 API 응답에 있고 채움률 100%다.**
   `packages/core/src/adapters/seoul-culture.ts:21`에 타입 선언까지 돼 있는데 매핑에서 누락.
   → seoul_culture는 제목 정규식이 필요 없다. 실제 필드를 쓰면 된다.

2. **"이상"은 하한 표기라 성인을 포함한다.** "8세 이상 관람 가능" = 어른도 봐도 된다.
   단순 substring 게이트는 정상 후보를 대량으로 잘라낸다.
   기존 테스트 픽스처 `seoul-culture.test.ts:14`가 정확히 이 문자열이다.

3. **상한없음 검사를 제목에 걸면 안 된다.**
   실측: 제목에 "이상"을 가진 culture 8건 **전부 오탐**이었다 —
   `이상원 개인전`(인명), `상, 상 이상: 모란조각대상`(전시명). 제목의 "이상"은 대상 표기가 아니다.

4. **게이트는 culture 전용이어야 한다. 전역에 걸면 안 된다.**
   실측: 제목에 아동 토큰을 가진 49건 중 **26건이 `seoul_jobs`의 "○○어린이집 · 보육 교사"**다.
   어린이집 구인은 성인이 지원하는 정상적인 부업 후보다. 전역 게이트는 이걸 다 지운다.
